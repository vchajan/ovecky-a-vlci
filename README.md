# Sheep Defender

Semestrální projekt v Pygame — hra, kde pes brání stádo ovcí před vlky.

## Spuštění

```bash
python -m venv .venv
source .venv/bin/activate     # Linux/Mac
# .venv\Scripts\activate      # Windows
pip install -r requirements.txt
python main.py
```

## Ovládání

- WASD nebo šipky: pohyb psa
- Esc: konec hry / pauza
